# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| Latest 1.x | ✅ |
| Older | ❌ |

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately via GitHub's **Security → Report a vulnerability** tab on this repository. We aim to acknowledge reports within 7 days and will coordinate disclosure before any fix is made public.
